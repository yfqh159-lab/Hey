# Hey 精简客户端实施记录

> 开发分支：`codex/p0-vpn-mainline`；基线：`65bdea3`。本文件记录已落到源码的变更，
> 不把静态检查等同于真机验收。真机结果只填写在
> [`device-acceptance.md`](device-acceptance.md)。

## 已落地变更

### 代理与 VPN 主链

- `dcfb355`、`050a0d9`、`d97735f`、`fe7fbbe`：真实心跳、失败清理、扩展内异常清理与跨进程状态校正。
- `7c7b678`、`ef6bf64`：默认 DNS 经代理，并在可用系统版本上保护核心进程网络，降低 DNS 泄漏与自身 TUN 回环风险。
- `7f2fe6b`、`335184e`：停止闩锁及事务化 VPN 状态文件，避免迟到的启动协程复活会话或半写状态误报。
- `97c1602`、`995d940`、`47a3a33`：本地代理状态独立处理；启动前等待实际 SOCKS 入口，运行中连续探测数据面，失败清理但不自动重连。
- `cc9ec16`、`36c7d85`、`5d112c5`：TUN 与本地 SOCKS/HTTP 成为明确的可选模式；首页显示当前模式，VPN 网络自动化不再影响本地代理。
- `9d5505f`、`dc1f8a0`：观察底层 Wi-Fi/蜂窝变化但不强制重启 VPN；新连接跟随系统默认承载。

### 节点导入与精简界面

- `b68c8f1`、`8e133a1`：相机/相册识别后展示预览，用户再次确认才保存，并对重复节点去重。
- `d8afe3d`、`3f382bd`、`608107e`：扫码、深链与系统分享保持被动；订阅只保存来源、不自动请求，导入不偷偷切换运行中的节点。
- `cb152f9`、`1105f77`：相机权限仅在用户进入扫码动作时申请，所有扫码入口统一处理授权。
- `16bc058`：日常添加流程隐藏代理链与策略组创建入口，既有底层配置仍保持兼容。

### Geo 数据

- `579f470`、`0a011b9`、`370f2b2`：内置默认发布源一次点击检查两个核心文件；默认与高级远程 `.dat` 都在大小、形态和 SHA-256 通过后才替换，本地导入也拒绝异常数据；失败保留旧文件与最后一次有效元数据。
- `d572f05`、`64be10c`：双文件事务、备份与进程中断恢复；冷启动先恢复 Geo 文件，再初始化 Xray 资源目录。
- `4c1f80c`：自定义资源名限制在沙箱数据目录内，并保留 `geoip`/`geosite` 核心名称，阻止覆盖或路径逃逸。
- 更新仍是手动触发；运行中不擅自重启代理，需用户重连后加载新数据。

### 可观测性与交付

- `ab64729`、`8a59556`：连接页显示经当前代理验证的出口 IP，并区分“数据面运行”与“外网已验证”。
- `e00eebf`、`f136d82`、`7d8bfea`：诊断脱敏、测速错误净化及 UI 进程恢复后的日志接管。
- `78171e4`、`7901a66`：校验预编译 AArch64 原生库，并在构建后确认五个关键 `.so` 已打入签名 HAP；构建脚本统一提供 `build/test/install/logs/targets/doctor`。
